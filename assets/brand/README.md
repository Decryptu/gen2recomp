# Brand assets

The project's logo and banner, for anyone writing about gen2recomp: an article,
a package listing, a link on a wiki, a talk slide.

| File | | |
|---|---|---|
| `logo.png` | 1000x1000, transparent | The cartridge on its own |
| `banner.png` | 1500x500 | The logo with the wordmark, for the top of a page |

The banner is drawn on a light background. Over a dark one, use `logo.png` and
set the wordmark in your own type rather than placing the banner on a panel.

`icon.svg` in the repository root is a separate thing: it is the application
icon Godot ships in a build, not one of these.

Please do not restyle the logo, recolour it, or use it in a way that suggests
this project endorses something else. Nothing here is a Nintendo, Game Freak or
Creatures asset, and none of it may be used to imply otherwise.

of what we authored.
