# Brand assets

Use these authored assets when writing about pokerecomp in articles, package
listings, wiki links or talks.

| File | Size and use |
|---|---|
| `logo.png` | 1000x1000, transparent cartridge mark |
| `banner.png` | 1500x500, logo and wordmark on a light background |

On dark backgrounds, use `logo.png` with a separate wordmark. Do not restyle or
recolour either asset or imply endorsement. Neither is a Nintendo, Game Freak
or Creatures asset.

`icon.svg` in the repository root is the Godot application icon, not a brand
asset. These files carry the repository's [MIT licence](../../LICENSE).
