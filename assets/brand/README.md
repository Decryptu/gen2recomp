# Brand assets

Use these authored assets when writing about gen2recomp, such as in an article,
package listing, wiki link or talk slide.

| File | Size and use |
|---|---|
| `logo.png` | 1000x1000, transparent cartridge mark |
| `banner.png` | 1500x500, logo and wordmark on a light background |

On a dark background, use `logo.png` and set the wordmark separately. Do not
restyle or recolour either asset, or imply endorsement of another project.
Neither is a Nintendo, Game Freak or Creatures asset.

`icon.svg` in the repository root is the Godot application icon, not a brand
asset. These files carry the repository's [MIT licence](../../LICENSE).
